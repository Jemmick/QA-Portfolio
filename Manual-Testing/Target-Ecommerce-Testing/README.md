# Target E-Commerce Manual Testing Project

This project demonstrates manual QA testing of key e-commerce workflows on Target.com.

## Project Scope

The testing focused on critical customer actions including:

- Product search
- Adding products to the shopping cart
- Cart quantity and pricing updates
- Cart persistence while browsing
- Checkout validation
- Successful progression through checkout with valid information

## Testing Approach

The project includes both positive and negative test scenarios designed to evaluate functionality, data consistency, business logic, validation, and user workflow behavior.

## Test Environment

- Website: Target.com
- Testing Type: Manual Functional Testing
- Platform: Web
- Browser: Safari

## Results

Executed test cases were documented with expected results, actual results, and pass fail status.

Detailed test cases are available in `Test-Cases.md`.
